# 拾词 · 本地英语单词学习

安卓手机和平板版本见 [APK 安装及使用说明](android/README.md)。以下为电脑端使用方式。

双击 **Launch.cmd** 即可启动并打开网站。地址是 http://127.0.0.1:8765 。运行后无需联网，数据不会上传。只关闭网页不会停止服务，下次双击启动会直接打开。

## 学习方式

1. 选择四级、六级、考研词汇或核心词汇，也可以学习常用短语。
2. 默认每轮 10 词，在右上角「每轮 10 词」中可改为 1–100 词。设置从下一轮生效；不足一轮时显示剩余词条。
3. 先勾选不认识的词，点击「查看全部释义」。本轮全部词条都显示中文，可修改勾选。
4. 点击「确认保存并下一轮」。确认不认识的词进入生词本；同一个词跨词书合并，保留来源。
5. 生词本支持速刷。未勾选表示已经认识，核对并确认后会移出生词本。
6. 可以暂停或切换词书，当前轮的勾选、释义步骤和已刷进度都会保留。
7. 学习页和词书浏览页可以「重置本书进度」。仅清空该书的已刷词、轮数和当前轮，其他词书、生词本及累计学习统计保留。
8. 词书和生词本浏览页支持按英文或中文搜索。

## 本地文件

- `data/books/*.json`：七本词书，UTF-8 格式，可阅读或编辑。
- `data/user/state.json`：设置、每本书进度、未完成的一轮、生词本和学习统计。
- `data/user/state.backup.json`：上一次成功保存的数据副本。
- 页面「学习设置 → 下载备份」也可以下载全部学习数据。

需要恢复备份时，先停止服务，再用备份替换 `data/user/state.json`。不要在服务运行时手动修改学习数据。复制整个项目目录即可备份词库和进度；不要仅复制网页文件。

## PDF 导出

词书卡片上的下载按钮、词书浏览页面、生词本均可导出 PDF。PDF 是 A4 页面，**左侧英文、右侧完整中文释义**，自动分页、重复表头，包含书名与页码。字体使用本机 Windows 黑体（`C:/Windows/Fonts/simhei.ttf`），嵌入 PDF 后可独立阅读。

## 词库来源和筛选

数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)，保留 MIT 许可文件 `data/ECDICT-LICENSE.txt`。这是一份社区词库，考试标签与词条释义不等同于当年官方大纲，也不保证覆盖每个考试要求。

| 词书 | 词条数 | 整理方式 |
|---|---:|---|
| 四级词汇 | 3,846 | ECDICT 的 `cet4` 分类 |
| 六级词汇 | 5,802 | `cet4` 与 `cet6` 合并去重，含四级基础词 |
| 考研词汇 | 4,801 | `ky` 分类 |
| 四级词汇核心词汇 | 1,200 | 四级书中优先选取非中高考基础词，再按公开词频排序 |
| 六级词汇核心词汇 | 1,500 | 六级书中采用相同筛选规则 |
| 考研词汇核心词汇 | 2,000 | 考研书中采用相同筛选规则 |
| 常用短语 | 188 | 本项目整理的常见表达 |

核心词汇书是学习用的重点精选，每本都是对应完整词书的子集；使用 BNC / 当代语料库中可用的较优词频排名，**并非按考试真题出现次数统计**。常用短语保存在 `data/phrases.tsv`。数据生成脚本 `tools/build_books.py` 保留了完整规则，只有重新构建词库时才需要联网。

## 运行环境

当前电脑已配置好启动入口。启动脚本优先使用环境变量 `WORD_STUDY_PYTHON` 指定的 Python，其次使用 Codex 内置 Python，最后使用系统 Python；运行环境须有 `reportlab`。启动会自动复用已有服务。

换到其他电脑时安装 Python 3.10+，然后在此目录执行：

```powershell
python -m pip install -r requirements.txt
python server.py
```

修改端口可执行 `python server.py --port 8766`。中文字体路径可通过 `WORD_STUDY_FONT` 指定（需要含中文字符的 TTF 字体）。

停止服务可关闭启动它的终端；通过 Launch.cmd 启动时，双击 **Stop.cmd** 即可停止。学习数据保存在 JSON 文件中，停止服务不会清空。
